# Workout Training Preparation

## About
This Java application helps people prepare for a workout by checking the training plan, available time, equipment, and energy level.

## Why Is It Useful?
It helps users organize their workouts and identify possible problems before starting training.

## How to Use
Run `Main.java` in IntelliJ IDEA. The program checks the workout and displays the result in the console.

## Design Pattern
The project uses the Facade pattern to combine several checks into one simple method.
